#能智能会议助手

本项目是一个本地优先的 AI 会议记录与纪要助手，面向企业内部会议场景，支持桌面录音、实时原文预览、会后转写整理、说话人辅助标注、会议纪要生成、历史记录和 Word 导出。

## 核心能力

- 桌面应用：基于 `pywebview` 打开本地 GUI 窗口。
- 原生录音：基于 `sounddevice` 采集麦克风音频，避免 WebView 麦克风权限问题。
- 实时原文：录音过程中调用火山引擎流式 ASR 展示实时文本。
- 最终转写：停止录音后基于完整音频进行最终转写，长音频采用分片兜底。
- 说话人辅助标注：基于本地 `Resemblyzer` 做声纹聚类，适合辅助整理，不承诺多人高精度识别。
- 会议纪要：调用豆包 LLM 生成结构化会议纪要。
- 历史归档：保存会议转写、纪要、音频路径，支持打开历史记录。
- Word 导出：将纪要内容导出为 `.docx` 文件。

## 技术栈

- 后端：Python、FastAPI、Uvicorn
- 桌面 GUI：pywebview
- 前端：HTML、CSS、Vanilla JavaScript
- 录音：sounddevice
- ASR：火山引擎豆包语音识别
- LLM：火山方舟豆包大模型
- 声纹辅助标注：Resemblyzer、librosa、scikit-learn
- 文档导出：python-docx

## 快速开始

1. 安装依赖：

```bash
pip install -r 依赖清单.txt
```

2. 配置密钥：

```bash
cp 配置与模板/火山密钥_LLM.example.py 配置与模板/火山密钥_LLM.py
cp 配置与模板/火山密钥_流式.example.py 配置与模板/火山密钥_流式.py
cp 配置与模板/火山密钥_录音文件.example.py 配置与模板/火山密钥_录音文件.py
```

然后编辑复制出来的 `火山密钥_*.py` 文件，填入自己的火山引擎 / 火山方舟凭证。

3. 启动桌面应用：

```bash
python3 启动程序.py
```

如果只想以浏览器方式调试：

```bash
python3 启动程序.py --web
```

## 数据安全说明

- 真实密钥文件、录音缓存、历史记录、调试日志默认不会提交到 Git。
- 录音音频默认保存在本地目录，用户可自行清理。
- 当前 ASR 和纪要生成依赖云端模型服务；说话人辅助标注在本地运行。
- 企业级落地可进一步替换为内网对象存储、私有化 ASR 或本地 WhisperX 方案。

## 注意事项

- `Resemblyzer` 属于轻量本地声纹方案，适合比赛演示和辅助标注，不适合承诺多人会议商业级 diarization 准确率。
- 长会议企业级使用建议接入录音文件识别、统一时间轴、私有化 ASR 或 WhisperX / pyannote 类能力。
